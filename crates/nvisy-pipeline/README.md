# nvisy-pipeline

[![Build](https://img.shields.io/github/actions/workflow/status/nvisycom/runtime/build.yml?branch=main&label=build%20%26%20test&style=flat-square)](https://github.com/nvisycom/runtime/actions/workflows/build.yml)

Pipeline action and provider traits with detection, redaction, and generation actions for the Nvisy runtime. Provides entity detection (regex, dictionary, checksum, tabular, manual, NER), policy evaluation, content redaction (text/image/tabular/audio), content generation (OCR, transcription, synthetic data), and audit-trail emission.
